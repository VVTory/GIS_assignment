## 项目内容

项目以公开遥感数据为基础，展示美国南部大平原 SGP 研究区的地表温度、植被指数和土壤湿度。主要能力包括按日期浏览与播放、覆盖率和质量诊断、地图位置查询、区域统计、同点多变量时序、双日期对比及地图/表格成果导出。EF仅作为可选工程派生图层展示，不宣称复现论文或完成站点精度验证。

系统采用 Vue 3、TypeScript、MapLibre GL JS、FastAPI、Rasterio、GeoServer 和 GeoWebCache。栅格地图服务通过 GeoServer/GWC 发布，数值查询与统计读取原始发布栅格；包含有界请求缓存、发布版本校验和 GeoServer 不可用时的本地瓦片回退。

## 启动和演示

1. 运行环境需 Python 3.12、Node.js 22、pnpm 和 Java 17；依赖安装步骤见根目录 README.md。
2. Windows 下在项目根目录运行：

       Set-ExecutionPolicy -Scope Process Bypass
       .\scripts\start-webgis.ps1 -OpenBrowser

3. 本机网页地址为 http://127.0.0.1:5175/，API文档为 http://127.0.0.1:8002/api/docs。服务绑定本机回环地址，教师不能通过该localhost地址远程访问。
4. 演示建议依次展示：日期日历与覆盖率 → 地图播放 → 质量诊断 → 点位查询和区域统计 → 同点三变量时序 → 日期对比 → PNG/PDF/CSV导出 → 架构与安全测试证据。
