## 1. 项目需求与目标

项目面向公开遥感数据的交互式浏览与解释。用户可以在网页选择变量、日期及地图位置，查看有效覆盖、质量状态、数值、时序和区域统计，再导出可用于课程报告的成果图与表格。研究区为美国南部大平原SGP子区，范围为西经98.5°—96.5°、北纬35.5°—37.5°。

数据由网络公开来源取得，不开展人工测绘。重点是GIS工程的全栈集成与正确解释；不要求逐式复现文献。EF保留为可选工程基线，不作为经过站点验证的遥感反演成果，也不等同于蒸散发量。

## 2. 数据和方法

观测期为2025年5月1日至8月31日，当前版本 local-2025-e9f6c73695-lst-celsius-v1 发布332个图层，包含121期NDVI、106天LST、90天EF工程基线和15天SMAP。另有研究区边界和本地Natural Earth水系、行政边界、城市参照底图。各日期的实际可用性由目录和处理报告决定。

| 数据 | 处理与含义 | 限制 |
|---|---|---|
| MOD11A1.061 LST | 读取比例因子与QC，筛除不合格像元并裁剪研究区；发布结果使用°C | 标称1 km晴空地表温度；云和QA会造成缺测，不等于气温 |
| MOD13A2.061 NDVI | 结合VI_Quality和pixel_reliability筛选，在前后合成期名义起始日之间插值 | 标称1 km、16天合成；每日展示不是每日独立观测，边缘日期不外推 |
| SMAP AM | HDF5提取原生中心、土壤湿度和QA，当前增强产品约9 km网格间距 | 网格间距不等于独立空间分辨率；点查询为30 km内最近有效格点，匹配中心可逐日变化 |
| EF基线 | NDVI覆盖度、温度干湿边与简化关系派生；质量不足或拟合异常拒绝输出 | 工程基线，非论文复现；无ARM站点精度验证 |

NDVI与EF无量纲，SMAP为m³/m³。科学分析不混合不同变量的单位和空间分辨率。三变量共用坐标与日历显示，但不表示同步观测、下尺度或多源逐像元融合。

来源、文件格式、QA、比例因子、源日期、算法参数、缺测原因及校验信息保存在 data/sample/input_manifest.json、processing_report.json、catalog.json 与 verification.json。SHA256仅在相应清单实际含校验值时声称已经计算。

## 3. 架构设计

系统分为离线处理层、数据发布层、数值服务层和前端交互层。

1. processing读取first_data中的原始数据，进行格式识别、质量筛选、单位转换、NDVI插值、SMAP提取和EF试算。
2. 生成的数值GeoTIFF、GeoJSON、预览与报告先进入临时目录，通过校验再切换data/sample；旧发布保留在data/releases。
3. GeoServer/GWC发布317个栅格日期的地图瓦片；FastAPI提供目录、数值查询、覆盖率、区域统计、时序、质量诊断和下载。服务不可用或发布登记失效时回退Rasterio瓦片。
4. Vue 3、TypeScript、MapLibre GL JS从目录加载变量与日期，显示地图、日历、查询结果、时序、质量叠加和导出工具。

网页请求XYZ瓦片，服务端负责与GeoWebCache TMS行号转换。地图显示使用真实重投影的EPSG:3857文件；数值查询、统计和GeoTIFF下载仍读取原网格，以避免显示插值影响分析结果。详细说明见 architecture.md。

## 4. 已完成功能

- 地图浏览：本地底图、研究区外淡化、细实线边界、比例尺、透明度与返回研究区。
- 变量与日期：目录驱动的变量切换、覆盖率日历、月份导航与高覆盖日期筛选。
- 点位与区域分析：源像元查询，矩形/多边形统计，以及SMAP原生格点查询与距离说明。
- 时序：缺测断线、时段选择、图表交互、同点LST/NDVI/SMAP三变量和CSV。
- 日期对比：同变量双图同步视野与共同色标，统计仍使用主日期。
- 日期播放：暂停、调速、循环、末日停止、加载等待和失败暂停。
- 质量诊断：原始QA支持的云、低质量、排除表面、源缺测及其他排除类别；缺QA时明确降级。
- 成果导出：数值CSV、真实GeoTIFF/GeoJSON，以及带标题、单位、日期、比例尺、来源、版本和图例的PNG/单页PDF。

## 5. 空间逻辑与数据正确性

栅格覆盖率分母是研究区内像元中心落入的候选源像元，分子是文件掩膜通过且数值有限的像元。区域统计仅使用有效值，保留有效零值，计算等像元权重的均值、最值与总体标准差；全缺测时返回空值，不填零。

SMAP区域统计只对已发布的有效格点等权计算；缺少缺失中心位置时无法恢复区域分母，返回“未提供”，不把有效格点比例说成面积覆盖率。

质量诊断以已发布有效掩膜为准。LST明确云标记可以解释云影响；NDVI质量源自插值两端的合成期，不是当天云图。SMAP不通过其QA推断云。

成果导出等待地图和质量层加载，日期或视图变化时拒绝导出错配成果。PDF为当前主图的地图图像，不是可编辑矢量地图。全研究区成果需要先返回研究区。

## 6. 缓存、安全与性能

API将查询与瓦片响应分别缓存在有界内存缓存中，GeoWebCache另有文件瓦片缓存。查询最多512项/32 MiB；瓦片最多512项/64 MiB、15分钟有效期。缓存键包含发布文件身份、样式/修订和请求内容，只有成功响应可缓存。数据或样式改变后旧登记与缓存失效，避免旧瓦片对应新数值。

API拒绝未知、重复参数和任意CQL，限制查询长度、请求体大小、几何位置数与计算像元窗口；文件路径解析后必须处于发布目录范围，XYZ索引有界。安全证据与不足见 reports/安全测试报告.md。

历史性能对照于2026年11月14日进行，采用旧样本单一点位URL、各60请求、并发1/5/10，比较API查询缓存开关。并发10时中位延迟从650.4 ms降到166.9 ms，吞吐从15.35次/秒到59.36次/秒，两组错误率均为0。它说明重复热点请求下缓存路径的收益，不代表当前332层数据、多点混合业务、持续公网压力或生产容量。完整记录见 docs/工程验收与启动.md 和 reports/webgis-benchmark-20261114T090942Z.json。
