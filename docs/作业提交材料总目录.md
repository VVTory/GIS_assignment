## 四、提交前尚需完成

1. 确认 Git 仓库位置并做一次干净提交；检查忽略规则和秘密扫描结果。
2. 按真实协作历史填写两个日志模板，检查时间、任务与修改对应关系。
3. 录制约3—5分钟演示，展示地图、日期播放、质量诊断、位置/区域分析、三变量时序和 PNG/PDF 导出。
4. 从空白目录或另一台电脑按说明启动，留下复现结果；当前“本机可运行”不等于跨机验收。
5. 核对课程项目报告正文、填学号姓名并导出正式PDF，按教师通知核对邮件收件人、附件大小和命名。

项目报告正文现已整理为课程项目报告.md；PDF版、个人信息和最终定稿仍由提交前核对。作业AI审查范围中的“矢量瓦片”目前没有MVT专项证据，现有SMAP为GeoJSON，应如实说明差距或另行补做，不能写成已完成。

当前资料没有证据支持 AI 生成代码比例，因此不填写或估算该比例。若课程另有 AI 使用比例要求，应通过仓库提交历史和真实协作记录核实后再报告。
