# 新版网页使用说明

2026年11月15日已重新处理新下载的数据：清点384个输入文件，发布2025年5—8月的332个图层。旧2019年结果保留在data/releases，原始文件保留在first_data。

## 更新后怎么打开

本机一键启动方法见 docs/工程验收与启动.md。在项目根目录的 PowerShell 执行 scripts/start-webgis.ps1；启动完成后访问 http://127.0.0.1:5175/。API 接口说明为 http://127.0.0.1:8002/api/docs，GeoServer 管理页面为 http://127.0.0.1:8600/geoserver/web/。不要直接双击 frontend/index.html。

新电脑或重新创建虚拟环境时，先按照README安装Python与前端依赖。已有虚拟环境更新依赖的命令为：

    .\.venv\Scripts\python.exe -m pip install -r backend\requirements-lock.txt

## 页面操作

1. 地图上方切换地表温度、植被指数、土壤湿度或可选EF，在左侧观测日历中选日期。默认显示NDVI；高覆盖日期用墨绿色系、低覆盖日期用暖色提示，当前日期只用赭橙边框标记。无数据日弱化显示，点击可查看未发布原因。
2. 查看有效覆盖率。栅格分母为研究区内源网格中心落入的全部候选像元，分子为文件掩膜通过且数值有限的像元；低于30%提示低覆盖。展开“覆盖率与缺测口径”查看说明。SMAP显示原生定位格点的有效比例，不表示面积覆盖率。
3. 点击地图：可收起的右侧栏显示当前位置、数值、单位，以及源像元行列/中心或SMAP匹配格点距离与QA。缺测显示横线和原因，不当成零。
4. 地图下方显示同一地点的逐日变化。当前观测期为2025-05-01至2025-08-31；没有发布结果或点位缺测时保留日期与空值，曲线断开。长时间范围只间隔显示日期标签，展开每日数值仍可查看全部日期。
5. 点击“矩形统计”，再点击地图两个对角；或点击“多边形统计”，逐点绘制并双击结束。后端将区域裁剪到研究区，计算有效数、有效比例、均值、最小值、最大值和总体标准差；最多100万候选源像元窗口。统计使用源数值文件，与屏幕缩放和透明度无关。切换主日期会清除旧区域结果，避免混淆。
6. 打开“日期对比”，选择另一日期。两张地图同步平移缩放，使用同一变量、相同色标。右图只作日期浏览；点击任一地图查询的位置和区域统计仍使用左侧主日期，右侧结果卡明确标注主日期。
7. “图层透明度”同时调节两图。“返回研究区”恢复研究区视野。
8. 点击位置查询、区域统计或时序旁的CSV按钮下载结果；“下载当前结果”下载真实GeoTIFF或GeoJSON。CSV使用UTF-8 BOM，保留日期、变量、单位、方法、数据版本、样本数及UTC导出时间，缺测值留空。区域CSV还保存实际裁剪后的几何范围与像元规则。
9. 右上角“数据与方法”展示来源、处理限制和报告入口。可用Tab切换链接、Esc关闭。

## 页面布局与图表

界面以纸白、墨绿和赭橙组织信息；界面主题不改变各变量的科学色带。标题区仅保留 SGP、中文项目名和美国南部大平原，不显示年份、生长季或时间范围。观测日期在日历、地图状态、图表和导出成果中明确标注。

桌面保留观测时间、地图与时序、分析结果三栏，左右栏均可收起。变量切换始终在地图上方，图例、比例尺、位置与数据状态合并在地图下方。手机首次进入先收起日历，可点“展开变量与日期”选日期。

页头将项目名称、数据与方法、左右面板开关集中在一行，不再为开关预留独立空白栏。地图上方的变量、播放、导出与统计工具采用紧凑间距，播放规则通过“播放说明”展开，加载与错误状态仍会直接提示。桌面地图高度随窗口调整，让图例与数据状态尽量进入首屏；手机工具自动换行，主要按钮保留至少 44 像素点击高度。

时序图明确显示变量、单位、完整日期刻度和产品日期（UTC）。缺测保持断线，横轴下的短线只标记缺测日期；整段缺测时纵轴不显示虚构数值。NDVI标注“合成期插值”，LST标注摄氏度换算说明。图表随栏宽调整刻度，支持悬停、轻触与键盘查看完整日期和数值。

## 地图背景与缺测识别

地图现在使用随项目保存的Natural Earth地理底图：浅灰陆地、淡蓝水系、州界及少量城市和州名。网页打开时不需要在线底图或字体服务。底图只用于辨认位置，不参与数值查询、覆盖率或区域统计。

研究区外覆盖半透明白色蒙版，仍可看到周边参照；研究区边界为细实线，外侧有淡色描边。研究区内缺测或未通过质量筛选的位置保留底图，图例中单独说明，不应理解为研究区外。初始视野和“返回研究区”按全部研究区多边形自动缩放，保留少量边距。

底图为研究区周边的概略地理参照，地图浏览范围限制在本地底图覆盖区。底图源数据版本、文件校验值和裁剪范围记录在frontend/public/basemap/sources.json；需要重新裁剪时运行scripts/build_map_context.py，输入为tmp/basemap-downloads中的缓存源文件。浏览器验收脚本为scripts/verify-map-context.cjs。

## 数据如何解释

- LST发布结果、地图色标、点位查询、时序、区域统计、CSV与GeoTIFF均使用摄氏度（°C = K − 273.15）；缺测值不参与转换。原始文件保留原单位，EF内部计算仍使用K。NDVI和EF为无量纲；SMAP为m³/m³。变量分开查询、绘图，不能把不同单位直接相减。
- NDVI是合成期插值，不是每日独立观测。LST是逐日观测。SMAP是原生粗网格，不是1公里产品。
- SMAP区域统计只对所选区域的有效格点等权统计。当前GeoJSON没有记录缺失格点的位置，无法计算该区域有效比例，页面显示“未提供”。全研究区格点有效比例来自处理记录中的有定位格点总数。
- 同一变量所有日期共享色标：NDVI为[-0.2,1]，EF为[0,1]，SMAP为[0,0.6]，LST取已发布日期共同数值范围。透明区域保持真实缺测。
- EF仍为未经站点精度验证的工程基线。当前没有执行SMAP下尺度或多源逐像元融合。

## 季节播放、质量诊断与成果导出

1. 选变量和起始观测日期，点击地图上方“按日期播放”；可设置 0.9、1.8 或 3.5 秒和循环。每帧显示该日期的有效比例，等待地图、覆盖率和已开启的质量诊断加载后继续。仅播放已发布日期；最后一天自动停止，开启循环则回到首日。点击地图查询、切换变量或导出会暂停，后台标签页等待恢复。SMAP 的比例为原生定位格点有效比例，不是面积覆盖率。
2. 点击“质量与缺测”，用原始 QA 解释空白位置。紫色为产品明确云标记，橙色为质量筛选不合格，蓝灰为水体、雪冰、阴影等排除项，灰色为源数据或质量标记缺测；有效值继续使用变量原色带。点击地图可读该位置分类。类别数量按源网格中心计数，不按屏幕图像计数。
3. LST 云来自 MOD11A1 QC_Day 的明确云标记；NDVI 分类来自插值前后合成期的 VI_Quality 和 pixel_reliability，界面列出源合成日期，不能解释为当天云图。SMAP 仅区分反演质量和缺测，不从 QA 推断云。原始 QA 不可用时只显示发布有效／缺测范围，明确告知无法细分原因。质量颜色是诊断叠加，不是遥感观测值；关闭后恢复原图。
4. 点击“导出地图 PNG”或“导出地图 PDF”，保存当前主日期和当前视图，包含中文标题、变量、单位、日期、有效比例、科学色带、真实比例尺、研究区边界、数据来源、版本、视图范围和导出时间。质量开启时同时加入质量叠加和依据说明。PDF 为单页地图图像。若需要全研究区成果，先点“返回研究区”；日期对比的右图不纳入导出。加载失败或导出等待期间更改日期、视图时会提示重试，避免生成日期与图面错配的成果。
5. 点击地图选位置，再点击时序区“同点三变量”，同一坐标的 LST、NDVI、SMAP 会并排分成三幅纵向图，共用所选日期范围、保留各自单位与纵轴，支持“导出三变量 CSV”。缺测日留空并断线。LST 为标称 1 km 逐日晴空观测；NDVI 为标称 1 km、16 日合成，当前逐日值为合成期插值；SMAP 为 AM 日产品、当前约 9 km 网格间距，有效日期不连续，网格间距不等于独立空间分辨率。SMAP 每天查询 30 km 内最近有效格点，匹配中心可能随日变化。三图不表示同步观测或多源逐像元融合。

## 后续增加数据

将原始MOD11A1温度/QC、MOD13A2的NDVI/VI_Quality/pixel_reliability及SMAP HDF5放在first_data。保留文件原名，子目录可按下载批次组织。运行scripts/process-sample.ps1，默认处理最新MOD11A1观测年份；可用-Year 2025指定年份。处理器不把不同年份拼成一条跨年时序，也不跨年插值NDVI。新产品、其他变量或不同网格仍需适配，不能仅复制任意TIFF就承诺发布。

脚本先在data/staging-*处理、检查真实文件和接口；通过后将旧data/sample移到data/releases，再切换新结果。加-PublishMapServices可同步到已启动的本机GeoServer。网页只显示catalog.json中status为ready的资产，处理完成后刷新网页。没有前后NDVI合成期的日期不外推；缺测、QA失败和不可靠EF拟合不补值。
