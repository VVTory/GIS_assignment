# WebGIS 启动与工程验收

## 直接打开

当前本机验收入口：<http://127.0.0.1:5175/>。网页、API 与 GeoServer 均绑定本机回环地址，不对局域网或公网开放。

## Windows 一键启动

双击项目根目录的“启动网站.cmd”，等待浏览器自动打开。三个服务会在后台运行，无需手动打开两个终端。电脑重启后需要重新双击启动。

也可以在项目根目录的 PowerShell 中执行：

    Set-ExecutionPolicy -Scope Process Bypass
    .\scripts\start-webgis.ps1 -OpenBrowser

脚本启动或复用 API 127.0.0.1:8002、GeoServer 127.0.0.1:8600 和网页 127.0.0.1:5175，检查网页和数据接口后打开浏览器。需要 Python 虚拟环境和前端依赖；GeoServer 另外需要 Java 17、GeoServer WAR 和 Jetty runner，本机服务包位于 tmp/services。地图服务不可用时由本地栅格提供瓦片。日志写入 tmp/logs。

日常启动复用已发布图层；更新数据后如需重新发布地图服务，使用 .\scripts\start-webgis.ps1 -RefreshLayers。

也可以只运行数值查询的本地回退模式：启动 API 和前端即可；瓦片会通过 Rasterio 从源栅格生成，区域统计、点位时序等数值服务不依赖 GeoServer。若 GeoServer 暂时不可用，地图瓦片会回退到 Rasterio 并返回来源响应头。

## GeoServer 与缓存

发布脚本：backend/scripts/publish_geoserver.py。它只允许向本机 GeoServer 发布，读取 data/sample/catalog.json 内状态为 ready 的栅格，创建按变量分组的样式、GeoTIFF覆盖层、GeoWebCache图层和数据修订清单data/sample/map_services.json。当前2025年批次为317个栅格日期。样式名包含色标范围指纹，重新上传已有图层时清除该层旧图块并等待清除任务完成，再登记修订。同一发布版本的数据、样式或算法修订号变化时，旧服务登记不再匹配，改用安全回退瓦片。

GeoServer 使用 WMS 和 GeoWebCache TMS 生成地图图块；API 将网页 XYZ 行号转换成 TMS 行号。GeoWebCache 文件缓存和 API 的内存响应缓存各自独立。API 查询缓存最多512项/32 MiB；瓦片缓存最多512项/64 MiB、15分钟过期；响应键包含发布目录、源文件身份、样式版本和请求内容。状态非200的响应不写入缓存。

验证脚本：backend/scripts/verify_geoserver.py。它逐层请求当前发布栅格的GeoServer/GWC瓦片，并重复请求API验证内存缓存命中。结果写在reports/geoserver-verification.json；该报告记录实际批次和数量。

当前地图服务上传map_rasters中的真实EPSG:3857最近邻展示文件，显式登记CRS和边界；数值查询、统计及GeoTIFF下载继续使用rasters中的原网格。scripts/verify_map_projection.py对每层含有效像元的z8瓦片与本地展示文件独立渲染结果进行透明掩膜及颜色对照；不能仅凭PNG返回200就认定位置正确。本次结果见reports/data-refresh-20261115-map-projection.json。

## 安全边界与解释规则

- 不接受任意 CQL、外部服务地址、任意样式名、未知或重复参数；查询字符串最多4 KiB。
- 区域统计请求体最多512 KiB，多边形最多5000个坐标位置，一次最多10个发布资产；仅允许 WGS84 且研究区范围内的有效几何。
- 下载和栅格路径在解析后必须位于当前发布目录内；瓦片 z/x/y 必须落在 XYZ 合法范围。
- 栅格覆盖率分母为研究区内源网格中心，SMAP比例分母为有定位的原格点；SMAP浅色格面按产品网格间距绘制，当前增强产品约9公里，不代表独立空间分辨率，点查询仍使用源格点值。
- 本项目未配置面向公网的用户认证、TLS、速率限制或多租户隔离。当前服务仅用于本机课程验收，不应把端口改成公网/局域网监听。

## 性能对照

可重复运行：backend/scripts/benchmark_webgis.py --requests 60。记录文件为 reports/webgis-benchmark-20261114T090942Z.csv 和同名 JSON。测试使用当前真实样本的一条点查询，同一URL重复请求，比较 API 查询缓存关闭与开启，各测60次、并发1/5/10；全部无错误。

| 1 | 开启 | 16.5 ms | 21.5 ms | 56.61 次/秒 |
