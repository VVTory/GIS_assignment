# 方法实现说明

当前范围以《项目范围与开发路线.md》为准。LST、NDVI与SMAP地图分析为主线，EF基线作为可选图层保留；微波方法、年度校准和ARM精度验证不作为本次WebGIS交付前提。

## empirical_tvx_v1

当前实现的是实施文档规定的工程基线：将NDVI端元映射为平方覆盖度，按覆盖度分箱取LST高分位拟合干边，用当前场景低分位定义湿边，再按简化的Priestley–Taylor型关系估计EF。默认无Ta时以Ts代理计算饱和水汽压斜率，并在诊断中标为 baseline_Ts_proxy。

此实现不等同于逐式复现2019/2020论文，也没有年度校准。只应对完成质量控制、单位核验、时间处理和同网格对齐的真实输入运行。样本不足、边界分母异常或D越界时保持无效，不强行截断生成EF。

## microwave_tvx_v1

未实现且不可用，移出本次必做范围。将来开展研究扩展时再核查方程、温度字段、长期约束、SMAP映射和年度校准；当前不作为可用算法对外显示。

## 验证

测试中构造的数组只用于检查数值路径，不代表遥感观测或模型精度。仓库没有ARM EBBR数据，因此N、r、RMSE、MAE、偏差和配对表均未产生。
