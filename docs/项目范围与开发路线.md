# 项目范围与开发路线

更新日期：2026年11月21日。本文记录用户确认后的范围；与较早实施文档冲突时，以本文为准。作业文档和提交状态统一见docs/作业提交材料总目录.md。

## 项目定位

名称：地表温度、植被与土壤湿度分析 WebGIS。

利用公开遥感数据展示地表温度、植被指数和土壤湿度，提供位置查询、区域统计、日期对比、时序分析及导出。现有EF工程基线保留为可选派生图层。核心是可运行、可解释、可检验的WebGIS及其工程设计。

## 不作为本次交付前提

- 文献逐式复现、微波驱动EF优化与年度参数校准。
- 多年温度极值、整年数据下载、ARM EBBR观测与精度评估。
- SMAP下尺度、多源逐像元融合及每日蒸散发量推算。
- 人工测绘、现场采样或自建观测站。

已下载的MOD03/MOD06/MOD07等文件保留，不要求纳入当前处理主线。

## 当前基础

已清点384个输入文件，当前2025年5—8月发布332个图层：121期NDVI、106天地表温度、90天可选EF工程基线、15天SMAP。离线处理、地图显示、像元查询、时序和来源追溯已跑通；2019年旧结果保留备份。实际数量及缺测日期以发布目录和处理报告为准。

网页分析功能已完成顺序1至6：覆盖率与缺测提示、矩形/多边形统计、点位时序图、变量色带与日期筛选、CSV与真实文件下载、同变量双日期对比。当前317个栅格接入GeoServer/GWC，已实施查询/瓦片缓存和版本失效；旧批次有API边界及缓存开关性能对照记录。站点接口仍为未就绪占位；公网部署、正式持续负载及新批次容量结论不在现有证据范围内。本次数据更新记录见reports/数据更新-20261115.md。

2026-11-21已补齐日期播放、真实QA质量诊断、PNG/PDF地图成果和同点三变量时序；18项新功能与20项交互回归有留存验收证据，见reports/演示与成果导出验收-20261121.md。本文档整理不等同于重新测试。

## 开发顺序与验收

| 顺序 | 功能 | 完成标准 | 新数据依赖 |
|---|---|---|---|
| 1 | 覆盖率与缺测提示 | 显示研究区有效覆盖率；说明分母和掩膜口径；识别低覆盖日期 | 无 |
| 2 | 区域统计 | 已实现矩形和多边形，返回有效像元数、有效比例、均值、最值和标准差 | 无 |
| 3 | 点位时序图 | 接入series接口；日期完整、缺测留空；不同变量与单位分开展示 | 无，增加日期可丰富效果 |
| 4 | 结果导出 | 导出查询/统计CSV，保留日期、单位、方法、样本数和数据版本；下载真实结果文件 | 无 |
| 5 | 日期对比 | 比较同一变量两个日期，统一色标和位置，说明有效范围不同 | 无 |
| 6 | 地图交互 | 日期/变量筛选、透明度、返回研究区、友好查询卡片和来源说明 | 无 |
| 7 | 服务与缓存 | 已在本机接入GeoServer/GWC；查询与瓦片分别缓存，发布/样式修订触发失效 | 无 |
| 8 | 安全与性能 | 已测试参数、几何、请求体、路径及瓦片范围边界；完成缓存开关耗时/吞吐/错误率对照 | 无 |
| 9 | 交付整理 | 同步文档、整理样本和依赖、录制演示、在新环境启动并保留记录 | 无 |

顺序1至8已有代码和本机验收记录；顺序9仍需整理跨机新环境复现与演示材料。原作业明确要求的组件、审查项和提交内容仍须保留。

## 数据边界

- 保留QA和缺测，不为填满地图伪造像元。
- 当前展示2025年5—8月观测期；早期2019年7天样本只保留历史备份，旧样本验收数量和性能不代表当前批次容量。
- NDVI合成期插值、LST逐日观测和SMAP原生粗网格分别说明；并排查看不等于数据融合。
- SMAP最近格点查询不标为1公里土壤湿度。
- EF标为工程基线，不宣称论文复现、精度验证或正式干旱判定。

## 推荐演示流程

打开地图 → 选择日期/变量 → 查看覆盖率 → 点击查询 → 点位时序 → 绘制区域统计 → 日期对比 → 导出 → 展示缓存、安全与性能记录。

该流程中分析、缓存、安全边界和性能对照已有本机验收证据；跨机部署、正式30秒持续负载与演示材料仍待补齐。
