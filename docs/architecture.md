# 当前工程架构

## 组件

- processing：读取first_data样本，执行清单、QA、单位转换、NDVI插值、SMAP格点提取和可选EF试算。
- data/sample：数值GeoTIFF、质量文件、PNG预览、GeoJSON、目录和报告。仅catalog中的ready资产公开。
- data/sample/map_rasters：从原网格真实重投影的EPSG:3857最近邻展示文件，避免地图服务对无EPSG编号的MODIS球体投影采用不同转换；查询、统计与数值下载继续读取原网格。
- frontend：Vue 3、TypeScript、Vite 与 MapLibre GL JS。地图使用本地背景样式，不请求第三方底图。页面从目录接口加载资产；尚无资产时展示明确空状态。
- backend：FastAPI提供健康检查、目录、报告、真实文件下载、覆盖率、变量色带、XYZ瓦片、源像元查询、日历时序与区域统计。栅格瓦片优先走GeoServer/GWC；服务不可用或发布修订失效时使用Rasterio安全回退。analysis模块使用Rasterio窗口、文件掩膜和Shapely几何校验/研究区裁剪。站点验证仍未就绪。客户端不传服务端路径、SQL或任意CQL。
- backend/app/algorithms：可独立测试的经验TVX基线公式，不负责读文件或发布数据。
- 质量与成果层：质量诊断按原始QA和已发布有效掩膜分类，原始输入变化使缓存失效；前端日期播放等待地图/覆盖率/质量就绪。同点三变量共用坐标/日历但独立纵轴，PNG/PDF导出保存主图当前视图并拒绝日期/图面错配。具体边界见reports/演示与成果导出验收-20261121.md。
- compose.yaml：本地API与前端开发服务，端口只绑定回环地址。

## 当前数据流

公开文件 -> 离线预处理 -> 数值结果与展示预览 -> 临时发布目录校验 -> 保留旧版本并切换ready发布目录 -> 网页筛选变量与日期 -> GeoServer/GWC XYZ瓦片或Rasterio回退；数值API读取原始发布数据 -> 结果卡、时序、区域统计和导出。2026-11-15更新为2025年观测数据，共332个图层，其中317个栅格在本机GeoServer注册，15个SMAP独立显示且不参与EF计算。

栅格覆盖率和统计以源网格中心落入区域为准，仅文件掩膜通过且有限的值参与计算；等像元权重，总体标准差。SMAP按有效原生格点等权统计，区域缺失分母不可恢复时返回null。客户端从数值API导出CSV，真实文件通过限制在发布根目录内的ID下载接口提供。

同变量两图使用共同色标；LST范围取全部已发布LST资产的共同最小值/最大值。Rasterio回退瓦片限制z≤14；原始数值统计每次最多10个资产、100万候选像元窗口、5000个几何位置；请求体最多512 KiB。点位时序保留缺日，最大日期跨度366天。

页面采用请求取消与响应序号检查，切换变量/日期时清除不适用的统计结果。日期对比双向同步相机，当前分析仍针对主日期。API使用独立的有界查询和瓦片内存缓存；缓存键包含发布文件与样式版本，发布变化后失效。Vite默认代理本机8000，可用VITE_API_TARGET指定独立测试API；Docker模式指向api:8000。

## 已知限制与后续

本机GeoServer/GWC已发布317个栅格日期，SMAP维持GeoJSON格点与按产品网格间距绘制的近似格面。标准产品约36公里，当前增强产品约9公里；网格间距不代表独立空间分辨率。后续应补跨机部署复现、正式30秒持续负载测试、TLS和用户认证；目前服务绑定127.0.0.1，仅适合本机课程验收。站点验证仍为未就绪占位。

论文复现、微波年度优化和ARM验证移出必做范围。现有Compose配置尚未在本机完成容器部署验收。
