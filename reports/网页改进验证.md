## 数据例证

- 研究区栅格候选源像元数为46,232。NDVI有效37,749，覆盖81.7%；2019-06-05 EF有效14,967，覆盖32.4%；2019-06-03 EF有效422，覆盖约0.9%，页面标低覆盖。
- EF示例源像元中心：经度-97.8215132322，纬度36.5708333298，2019-06-05真实值0.5762393475，源行172/列304。
- 浏览器EF矩形统计样本：有效10,310，均值0.6171978196，总体标准差0.2274191770。实际点击生成的精确几何与分母见browser-verification.json。
- 同一点的其他EF日期可能缺测；不能因为某日资产发布就把该位置当成有效。实际图表与CSV保留这种差异。

## 本轮工程验收

- GeoServer 2.28.2 和 GeoWebCache 1.28.2 已在本机实际启动；发布14个真实栅格日期，逐层核验服务目录、WMS/TMS瓦片PNG、GeoWebCache 命中/未命中和 API 重复请求缓存。逐资产结果见 reports/geoserver-verification.json。
- 发布清单写入 data/sample/map_services.json，按源栅格、方法版本、数据目录和样式版本计算 revision；revision 不一致时不使用旧地图服务登记。GeoServer 故障时用本地 Rasterio 出瓦片，保持网页地图可见。
- backend/app/http_boundary.py 区分查询缓存和瓦片缓存；缓存容量有界、失败响应不缓存、发布身份变更后旧缓存失效。安全测试覆盖 CQL/未知/重复参数、查询长度、超大统计请求、多边形有效性、资产路径越界和 XYZ 瓦片范围。
- 性能对照以真实样本点位 API 查询、60次请求/组、并发1/5/10比较查询缓存关闭/开启。错误率均为0。缓存开启后中位延迟分别为16.5、76.2、166.9 ms，关闭时为41.1、208.6、650.4 ms。完整指标和限制见 docs/工程验收与启动.md 及 reports/webgis-benchmark-20261114T090942Z.*。
- 当前仍是本机课程验收环境：未完成公网身份认证、TLS、速率限制、30秒正式负载压测、跨机部署或演示录屏，不宣称为生产就绪。

当前大栅格在线预览有规模上限，不应直接用大范围文件替换样本并承诺性能不变。数据和处理限制详见 docs/网页使用说明.md。
